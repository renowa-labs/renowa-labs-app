# Subject

Renowa Labs ilə ödənişli təcrübə proqramı üzrə əməkdaşlıq

# Body

Salam, hər vaxtınız xeyir. Ümid edirik, xoş bir həftə keçirirsiniz.

Biz Renowa Labs olaraq yerli və qlobal bazar üçün texnoloji, əsasən Süni İntellekt yönümlü həllər üzərində çalışırıq. Hazırda marketinq və dizayn komandamızı genişləndiririk və əməkdaşlıq edə biləcəyimiz partnyorlar axtarırıq. Səhifəniz diqqətimizi çəkdiyi üçün əlaqə saxlayır və ödənişli təcrübə proqramı üzrə əməkdaşlıq təklifimizi sizə təqdim etmək istəyirik.

İstiqamət sahələrimiz:

- UI/UX dizayn və istifadəçi təcrübəsi
- Brendinq və vizual identiklik
- Rəqəmsal marketinq strategiyaları
- Sosial media və kontent idarəetməsi
- Reklam kampaniyalarının optimizasiyası
- İstifadəçi analitikası və performans təhlili

Nələr təklif edirik:

- Yerli və qlobal layihələrdə çalışma və portfolio yaratma imkanı
- Sahənin peşəkarlarından mentor dəstəyi
- Süni İntellekt dəstəkli dizayn və marketinq alətləri üçün istifadə krediti
- Performans əsaslı tam zamanlı komandaya qoşulma fürsəti

Əgər maraqlı olarsa, nəticələri ilə fərqlənən tələbələrinizin CV və portfoliolarını info@renowa-labs.com ünvanına göndərə bilərsiniz.

Hörmətlə,
Renowa Labs komandası
